# Curriculum map

| Certificate theme | LaunchOps artifact |
|---|---|
| HTML, CSS and JavaScript | `frontend/src/` UI and responsive styling |
| Git and GitHub | repository history and `.github/workflows/ci.yml` |
| React front end | React client with stateful list, create, edit and delete flows |
| Python and Django | `backend/` REST API and data model |
| SQL and relational data | Django ORM with SQLite persistence |
| Containers and cloud-native concepts | `Dockerfile`, `compose.yaml`, frontend nginx container |
| Microservices and API design | separately run client/API, JSON REST contract |
| Capstone deployment/DevOps | local container composition and a CI system check |

This maps a single retrospective portfolio app to current public course topics. It does not claim to represent the exact capstone prompt completed by the learner.
